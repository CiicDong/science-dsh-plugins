# Science DSH Plugins Collection

这个仓库收集了我认为重要的 DSH 相关项目。

## 项目列表

- [dsh-plugins](https://github.com/CiicDong/dsh-plugins) - DSH 插件集合

## 使用方法

克隆这个仓库及所有子模块：

```bash
git clone --recurse-submodules https://github.com/zhangdong/science-dsh-plugins.git
```

或者先克隆主仓库，再初始化子模块：

```bash
git clone https://github.com/zhangdong/science-dsh-plugins.git
cd science-dsh-plugins
git submodule update --init --recursive
```

## 更新子模块

```bash
git submodule update --remote --merge
```
